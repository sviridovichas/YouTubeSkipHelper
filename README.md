# Пропуск рекламы · YouTube Skip Helper

Бесплатное приложение для Android, которое нажимает доступную кнопку «Пропустить» в официальном YouTube. Актуальная версия: **0.3.0-native**.

**Рекомендуемая проверенная модель — Samsung Galaxy A33 5G (SM-A336B).** Владелец подтвердил реальные пропуски рекламы и успешную работу после перезагрузки; 4 ноября 2026 года повторно сообщил об успешной работе приложения. Это результат проверки на одном телефоне. Другие модели и версии прошивки отдельно не проверены. Минимальное требование приложения — Android 8.0 (API 26).

## Установка и включение

1. Скачайте APK на телефон и установите его. Если Android запросит разрешение на установку из выбранного браузера или файлового менеджера, решение принимает владелец телефона.
2. Откройте «Пропуск рекламы», прочитайте описание доступа и нажмите «Включить службу».
3. В специальных возможностях Android включите службу «Пропуск рекламы». Если система ограничивает включение для приложения из файла, следуйте подсказкам Android в сведениях об этом приложении.
4. На Samsung оставьте **ярлык быстрого доступа к службе выключенным**, а саму службу включённой: случайное нажатие ярлыка может отключить автопропуск.
5. Вернитесь в приложение, убедитесь, что автопропуск включён, и откройте YouTube.

Для повседневной работы версии 0.3.0 компьютер, ADB и отладка по Wi-Fi не нужны. Службой управляет Android. Для паузы выключите автопропуск в приложении; для полного отключения выключите службу в специальных возможностях.

## Возможности и ограничения

- Распознаёт точные русские и английские подписи кнопки пропуска и известные идентификаторы элементов. Проверяет актуальное окно YouTube, фиксированные координаты не использует.
- Нажимает только доступную кнопку пропуска. Непропускаемую рекламу не убирает, видеопоток не изменяет и рекламу не ускоряет.
- Работает с официальным приложением YouTube для телефона; браузер, YouTube Music и Android TV не поддерживаются.
- После обновлений YouTube или Android работа может измениться. Расход батареи и все варианты масштаба/поворота отдельно не измерялись и не проверялись.
- Счётчик показывает принятые Android команды нажатия, а не независимое подтверждение исчезновения каждого рекламного ролика.

## Доступ и данные

Служба специальных возможностей читает доступную структуру окна YouTube и нажимает распознанную кнопку. В APK нет разрешения INTERNET, аналитики, записи или передачи экрана. На телефоне сохраняются согласие, переключатель, счётчик, время нажатий и технический класс последней ошибки. Резервное копирование отключено.

## Проверка и обновления

Перед выпуском 0.3.0 выполнены 27 модульных JVM-тестов и lint без замечаний, проверена подпись APK v2. APK в этом выпуске совпадает по SHA-256 с ранее установленным проверенным файлом. Повторная сборка для публикации не выполнялась.

Комплектный APK имеет отладочную подпись. Для обновления поверх установленной версии нужна та же подпись; самостоятельно собранный APK может иметь другой ключ. Ключи подписи и ADB-доступа не публикуются.

## Сборка

Распакуйте архив исходников. Нужны JDK 17, Android SDK 35 / Build Tools 35.0.0; используются Gradle Wrapper 8.11.1 и Android Gradle Plugin 8.9.2.

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

Linux/macOS: `bash ./gradlew testDebugUnitTest lintDebug assembleDebug`.

APK: `app/build/outputs/apk/debug/app-debug.apk`. Скрипт `build-local.ps1` предназначен для исходной рабочей машины; на другом компьютере используйте Gradle Wrapper со своим Android SDK.

Проект не связан с YouTube, Google или Samsung.
